This project demonstrates the integration of Python with the Google Gemini API to generate AI responses. The main objective is to send a prompt to an AI model and receive a meaningful response. The project contains three files: main.py, .env, and .gitignore. The main.py file contains the main Python program that connects to the Gemini API. The .env file stores the Gemini API key securely using the variable GEMINI_API_KEY. The .gitignore file prevents sensitive and unnecessary files from being uploaded to GitHub. It ignores .venv/, .env, __pycache__/, and .pytest_cache/.

The project uses Python libraries such as os, json, and urllib.request. It also uses the python-dotenv package to load environment variables. First, the program imports the required libraries and loads the .env file using load_dotenv(). Then, it reads the API key using os.getenv(). If the API key is missing, the program displays an error message. Next, it prepares a JSON payload containing the prompt, "What is Artificial Intelligence? Explain in simple words." The program sends a POST request to the Gemini API using urllib.request. The API processes the prompt and returns a response in JSON format. The program extracts the generated text and displays it in the terminal.

To execute the project, install the required package using pip install python-dotenv and run the program using python main.py. The try-except block handles errors during API communication. The project requires Python, a valid Gemini API key, and an internet connection. The API key should never be shared publicly and must remain inside the .env file. Overall, Week 1 provides a basic understanding of Large Language Models (LLMs), API integration, environment variables, JSON handling, and AI-generated responses using Python.
