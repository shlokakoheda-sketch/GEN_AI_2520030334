Week-6 focuses on performing a baseline evaluation of a Large Language Model (LLM) using a predefined set of questions stored in a `golden_set.json` file. The project uses the Ollama platform with the Llama 3.2 model to generate answers for each question and compares the generated responses against expected answers using keyword-based scoring. For every question, the program checks the presence of expected keywords in the model's response, calculates a score based on keyword matching, and assigns a PASS or REVIEW status depending on the score. It also displays the generated answer, expected answer, matched keywords, missing keywords, and evaluation score for each question.

The project automatically processes all questions in the dataset and stores the evaluation results in a `baseline_results.csv` file for further analysis. The final summary includes the total number of questions, successful responses, passed questions, questions requiring review, failed requests, and average keyword coverage. This baseline evaluation helps measure the initial performance of the LLM, identify gaps in its responses, and establish a reference point for future improvements in model accuracy, response quality, and evaluation methods.
