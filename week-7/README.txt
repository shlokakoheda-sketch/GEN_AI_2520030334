This project demonstrates the basic concept of autoregressive text generation using a simple next-word prediction model implemented in Python. It uses a small training text containing sentences related to students, teachers, studying, and learning. The program tokenizes the text into individual words and builds a probability-based word transition model by storing the words that can follow each current word. Using this model, the program learns simple word-to-word relationships from the training text and demonstrates how text can be generated step by step based on previously generated words.

The text generation process begins with a user-defined starting word and repeatedly selects the next word using `random.choice()` from the available word sequences stored in the model. Each predicted word is added to the generated sentence and becomes the input for the next prediction until the specified word limit is reached or no further prediction is available. The program displays the generated text as output, demonstrating the fundamental idea of autoregressive generation, where each new word depends on the previously generated sequence. This experiment helps understand next-word prediction, sequential text generation, and the basic working principle behind more advanced language generation models.
