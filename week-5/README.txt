This project is designed to estimate the cost, token usage, and capacity requirements of an AI-based application before deployment. It uses a Python-based budget calculation system that considers the expected number of requests per day, average input and output tokens per request, API pricing, peak request rates, provider capacity limits, and daily and monthly budget constraints. The project uses environment variables stored in a `.env` file to configure these values, making it easier to adjust usage assumptions, pricing, limits, and budget settings without modifying the main Python code. It also incorporates a safety margin to account for unexpected usage increases and peak traffic conditions.

The program calculates the estimated daily input and output token usage, total tokens consumed per day, daily and monthly API costs, peak requests per minute (RPM), and peak tokens per minute (TPM) with the configured safety margin. It then checks whether the estimated usage stays within the specified RPM and TPM limits and whether the projected costs remain within the daily and monthly budgets. Based on these checks, the program displays a token economics report and provides a final recommendation indicating whether the application is within the configured planning limits or whether the assumptions, budgets, or system design need to be revised. The project also includes unit tests to verify cost calculations, capacity checks, and budget-related conditions, helping ensure the reliability and accuracy of the budgeting system.
