This project demonstrates a flexible Python-based integration with Large Language Models (LLMs) using multiple AI providers. The main objective is to connect the application with either Google Gemini or Ollama to generate AI responses. The project contains six files: `main.py`, `llm_client.py`, `test_client.py`, `.env`, `.gitignore`, and `requirements.txt`. The `main.py` file acts as the main application and allows users to select between Gemini and Ollama. The `llm_client.py` file contains the provider classes and common client interface. It uses an abstract base class called `LLMProvider` to define a common structure for different AI providers. The `GeminiProvider` connects to Google's Gemini API, while the `OllamaProvider` connects to a locally running AI model called Llama 3.2.

The Gemini provider includes multiple model options and fallback mechanisms to handle temporary server errors. It also retries requests when temporary issues occur. The Ollama provider sends requests to the local Ollama server using the `requests` library. The `LLMClient` class provides a common method called `generate()` to communicate with different providers. The `test_client.py` file contains a unit test using Python's `unittest` framework and a fake provider to check whether the client generates the expected response. The `.env` file stores the Gemini API key securely, while `.gitignore` prevents sensitive and unnecessary files from being tracked. The `requirements.txt` file lists the required packages: `python-dotenv`, `pytest`, `google-genai`, and `requests`.

To execute the project, install the dependencies using `pip install -r requirements.txt`. Run the application using `python main.py`, select either `gemini` or `ollama`, and enter your question. For Gemini, a valid API key must be available in the `.env` file. For Ollama, the Ollama application and the Llama 3.2 model must be installed and running locally. The program validates user input and handles errors during API communication. The unit tests can be executed using `python -m unittest test_client.py`. Overall, Week 2 provides an understanding of multiple LLM providers, object-oriented programming, abstraction, API integration, fallback mechanisms, error handling, and unit testing in Python.
