This project focuses on comparing different tokenization techniques used in Natural Language Processing (NLP) to understand how text is converted into smaller units that machine learning models can process. It implements three tokenizer approaches: Byte Pair Encoding (BPE) using GPT-2, WordPiece using Multilingual BERT, and SentencePiece using XLM-R. These pretrained tokenizer models are loaded through the Hugging Face Transformers library. The project tests sample sentences in English, Telugu, and Hindi to observe how each tokenizer handles different languages, words, and text structures. Tokenization plays an important role in NLP because it helps language models represent text efficiently while handling common words, rare words, and multilingual content.

The Python script automatically loads all three tokenizer models and processes each sample sentence individually. For every language, it displays the original input text, the tokens generated by each tokenizer, the corresponding token IDs, and the total number of tokens produced. This makes it easier to observe and compare the differences in tokenization across the selected algorithms and languages. The project also provides a practical understanding of how subword tokenization works, how different tokenizers represent the same sentence in different ways, and how tokenization influences text processing in multilingual applications such as translation, chatbots, text classification, and other language-based AI systems.
